# DESIGN.md — AgriSuri PH: Product Scope & Features

## 0. 设计立场

这份材料讲的是一款**已经写出来的软件**。所有视觉证据都应该是可核对的：界面结构、权限矩阵、闸门顺序、真实的两组准确率。
因此全篇不使用任何摄影素材——用照片去表现"田间病害"会把一款 UI 产品包装成研究成果，也容易让评审误以为照片是测试样本。
视觉载体只有四类：**UI 结构示意（Box 搭建，结构取自真实 markup）、流程图（SVG）、数据图（Chart）、排版（巨型字 + 网格）**。

> 生图说明：本环境未提供可用的图像生成工具，且本项目主体为软件界面，不适用具象摄影主视觉。全部 L1/L2 视觉以 SVG / Box 结构图 / Chart 承担，属于设计原则中"结构化、低语义元素"允许范围。

## 1. 画布与母版

画布 1280 × 720。三区母版：

| 区 | 垂直位置 | 高度 | 规则 |
| :- | :--- | :--- | :--- |
| A · 标题块 | 0–120px | 120px | 上 padding 20；眉标 13px + 主标题 34px，左对齐，左边界 72px |
| B · 内容区 | 120–660px | 540px | 一切正文、图表、示意图；禁止越界 |
| C · 页脚条 | 660–720px | 60px | 左：`AgriSuri PH · Product Scope`；右：`NN / 19`；13px |
| 页面 padding | 上下 20px，左右 72px | — | 安全区内排布 |

封面 / 章节扉页 / 结束页：省略 C 区，改用全幅深色底，页码不显示。
所有常规内容页 A/C 区位置**逐页完全一致**。

## 2. 颜色系统（4 个 hex，全部取自产品自身的品牌 token）

| 角色 | hex | 来源 | 用途 |
| :- | :--- | :--- | :--- |
| INK 深墨绿 | `#0B1F14` | 品牌深绿的压暗版 | Hero 页 / 章节扉页底色；浅底页的正文色 |
| GREEN 主绿 | `#056526` | `--green-900`（theme-color） | 主色：标题强调、结构线、表头、图表主系列 |
| LIME 青柠 | `#A4DA22` | `--lime-500`（logo 亮叶） | 强调色：只出现在焦点元素——巨型数字、当前步骤、关键标注 |
| PAPER 纸白 | `#F5F8F2` | `--green-050` 提亮 | 浅底页背景、深底页的反白文字 |

派生（不新增 hex）：
- 弱化文字 = INK 或 PAPER 加 `opacity 0.55`
- 分隔线 = INK `opacity 0.12`；深底页为 PAPER `opacity 0.18`
- 卡片底 = `#FFFFFF` 叠在 PAPER 上，或 PAPER `opacity 0.04` 叠在 INK 上

### 2.1 面积分配

| 页型 | INK | GREEN | LIME | PAPER/中性 |
| :--- | :--- | :--- | :--- | :--- |
| 浅底 supporting（04/08/09/11/12/15/16/18） | 文字 ≈12% | ≤ 12% | ≤ 5% | 剩余 70%+ |
| 深底 hero（01/05/07/13/17/19） | 70–80% | ≤ 10% | 12–18% | 剩余 |
| 章节扉页（03/06/10/14） | 88% | — | 10%（巨型编号） | 2% |

### 2.2 渐变与半透明
- 深底页背景：`linear-gradient(150deg, #0B1F14 0%, #0B1F14 55%, rgba(5,101,38,0.55) 100%)`
- 章节扉页巨型编号：LIME `opacity 0.16`，压在标题下方作纹理，不抢字
- 卡片阴影：`0 8px 24px rgba(11,31,20,0.07)`（浅底）/ `0 8px 24px rgba(0,0,0,0.35)`（深底）
- 叠加图元：底层 `opacity 0.12–0.2`

## 3. 字体系统（2 套家族）

- **Georgia**（衬线，编辑感）：章节编号、巨型数字、金句、封面主标题
- **Segoe UI**（无衬线，界面感）：页面标题、正文、标签、表格、页脚

| 层级 | 字体 | 字号 | 字重 | 行高 | 字距 | 用途 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| 封面主标题 | Georgia | 84 | bold | 1.05 | -1 | 仅封面 |
| 章节编号 | Georgia | 190 | normal | 1.0 | -4 | 章节扉页背景数字 |
| 章节大字 | Georgia | 54 | bold | 1.15 | -0.5 | 章节扉页标题 |
| 巨型数据 / 锚点 | Georgia | 96–120 | bold | 1.0 | -3 | 每页 ≥1 个视觉锚点 |
| 页面主标题 | Segoe UI | 34 | 700 | 1.25 | -0.6 | A 区固定 |
| 眉标 eyebrow | Segoe UI | 13 | 600 | 1.2 | 2.4 | A 区标题上方，大写 |
| 卡片标题 | Segoe UI | 20 | 600 | 1.35 | 0 | 卡片头 |
| 正文 | Segoe UI | 17 | 400 | 1.62 | 0 | 段落、列表 |

| 页脚 / 页码 | Segoe UI | 13 | 400 | 1.4 | 0.5 | C 区 |

## 4. 信息密度

- 常规内容页留白 ≤ 35%；本 deck 目标 18–26%。
- 卡片填充率 ≥ 85%：卡片内"标题—正文—尾注"三段撑满，尾注用 `marginTop: 'auto'` 钉底。
- 单页图元 ≤ 3 个；图元总面积 ≤ B 区 60%。
- 每页至少 1 个视觉锚点：≥ 72px 数字 / ≥ 40% B 区的结构图 / 深色满幅块。
